Conectar SQL

La conexión SQL ahora corre localmente en tu PC, usando el mismo enfoque de System.Data.SqlClient que ya te funcionaba. La página pública no intenta entrar a 127.0.0.1, por eso desaparecen CORS, “Acceso a la red local” y Failed to fetch.

1. Si es la primera vez o querés actualizar: descargá y ejecutá el conector.
2. El conector inicia el servicio local y vuelve a abrir Capitán Rodolfo.
3. Conectás → elegís base → lista tablas → volvés a Capitán Rodolfo.
⬇ Instalar / actualizar conector Abrir conector local →
